ASSISTANT:
Streamlit turns a **Python script into an interactive web app**. In your project, it’s the interface for exploring the analysis.

When you run:

```sh
.venv/bin/streamlit run app.py --server.address localhost
```

Python starts a local server, and you open its address in your browser. The app runs on your computer.

Your project has three main parts:

| Part | Role |
|---|---|
| Analysis scripts | Calculate spatial evidence and target rankings and save the results |
| `app_data.py` | Load saved evidence and prepare barcode-aligned map data |
| `app.py` | Display tables, controls, maps, explanations, and downloads |

**When you change a control, Streamlit generally reruns the Python script from top to bottom**, using the new selection. It remembers widget values, and caching lets it reuse expensive data loads.

For example, selecting a different mouse updates the spatial map and mouse-specific evidence. It **doesn’t recalculate the main ranking**, because that ranking already combines the saved 48/72-hour results. Expression maps load the relevant mouse’s source counts and prepare normalized expression for display.

A concise TA explanation is:

> “Streamlit provides the interactive interface for my analysis. It loads precomputed rankings and lets users inspect each candidate’s evidence and spatial expression. Changing the view doesn’t change the underlying ranking model.”

Your app is currently local; using Streamlit doesn’t automatically publish it online.
