ASSISTANT:
Today I added the calculations that turn raw RNA counts into comparable gene measurements and an exploratory collagen score.

**1. Normalize counts across spots**

Spots have different total RNA counts, called their **library sizes**. A spot with more measured RNA can have higher gene counts simply because more RNA was captured.

For each gene at each spot, we calculate:

```text
normalized expression = ln(1 + gene count / library size × 10,000)
```

Dividing by library size adjusts for total measured RNA. Multiplying by 10,000 gives a common scale. The logarithm compresses large differences, while adding one lets zero counts stay zero.

**2. Define a small collagen panel**

I chose `Col1a1`, `Col1a2`, and `Col3a1` because they encode collagen components relevant to your extracellular matrix question. This makes the score a measure of **relative collagen gene activity**, rather than a complete measure of fibrosis.

We had already explored these genes previously, so this panel is not an independently validated discovery.

**3. Calculate the score**

For each panel gene, I compare its normalized expression with that gene’s average across all 348 measured spots:

```text
standardized value = (expression − reference average) / reference standard deviation
```

The score is the average of the three standardized values.

- **Positive:** higher relative collagen gene activity.
- **Negative:** lower relative activity.
- **Zero:** average standardized activity for this reference—not necessarily no collagen expression.

The same reference must be used when comparing mice or time points. Recalculating the reference separately for each group would change what zero means.

**4. Handle special cases and test the calculations**

I added five tests alongside the three existing loader tests. They check that identical profiles score exactly zero, proportional increases in sequencing depth leave normalized expression unchanged, a known expression difference gives the expected scores, and invalid marker selections fail clearly.

A spot with zero total RNA gets a missing score because division by zero is undefined. A gene with no variation contributes zero to the score.

**All eight tests pass.** I also added `inspect_scores.py` so you can run the calculation, documented the method in `SCORING.md`, and updated the README and checklist.

The source data remain unchanged. This currently runs on the **348-spot subset**; full-data integration is still planned for checkpoint 2.

ASSISTANT:
I combined standard mathematical methods into a simple scoring rule for this project. **The normalization and standardization formulas are established methods; the choice to average these three collagen genes is our modeling decision.**

The normalization starts with a proportion:

```text
gene count / total counts in the spot
```

Suppose one spot has 10 collagen counts out of 1,000 total counts, and another has 20 out of 2,000. Both have the same proportion: **1%**. Their raw counts differ, but their relative expression is equal.

We multiply by **10,000** to express that proportion on a convenient common scale. Both spots would have 100 counts per 10,000. This number is a convention, not a biological threshold.

Then we apply:

```text
ln(1 + normalized count)
```

The logarithm compresses large values so very high expression has less numerical dominance. Adding one makes zero counts valid: `ln(1 + 0) = 0`.

Next, we use the standard **z-score formula** for each marker:

```text
(expression − marker average) / marker standard deviation
```

Subtracting the average centers the marker at zero. Dividing by its standard deviation expresses differences in units of that marker’s variation. This gives genes with different expression scales a comparable contribution.

Finally, I defined:

```text
score = (Col1a1 z-score + Col1a2 z-score + Col3a1 z-score) / 3
```

Equal weighting is a transparent starting choice; we haven’t learned weights from data or established that equal weights are optimal.

This construction also meets your proposed identical-profile check: if every spot has identical expression, each marker has zero variation. Because ordinary z-scores would divide by zero, **we explicitly define constant markers’ contributions as zero**.

The formula is therefore an exploratory measure of relative collagen RNA activity. Its mathematical properties are tested; its biological usefulness still needs evaluation.
